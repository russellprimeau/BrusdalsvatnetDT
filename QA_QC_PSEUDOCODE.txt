    "Temperature (max/min)":          [-40, 40]°C,
    "Humidity (relative)":            [0, 100]%RH
  }

  // Apply threshold-based exclusion
  for col, [min_val, max_val] in thresholds.items():
    mask = (df[col] < min_val) OR (df[col] > max_val)
    df.loc[mask, col] := np.nan

  // Special case: set negative solar radiation to 0 (not flagged)
  df["Shortwave (Solar) Radiation"] :=
    where(df["Shortwave (Solar) Radiation"] < 0, 0,
          df["Shortwave (Solar) Radiation"])

  // Replace "NAN" strings with np.nan
  for col in df.columns:
    df[col] := df[col].apply(lambda x: np.nan if x == "NAN" else x)

  // Data type conversion
  df.iloc[:, 1:] := apply(pd.to_numeric, errors='coerce', downcast='float')

================================================================================
DATA ALTERATION IMPACT SUMMARY
================================================================================

SondeHourly & PFLStep:
  Input:  Raw sensor readout (100%)
  NaN replacement:  ~<1% (mostly "NAN" strings)
  Rounding:  ALL values to 3 decimals
  Output:  Minimally altered (~99% of raw values retained)

Weather (All_time.csv):
  Input:  Raw sensor readout (100%)
  NaN replacement (routine):  ~2-5% (threshold violations)
  Special handling:  Negative solar radiation forced to 0
  Output:  ~95-98% of raw values retained (flagged violations → np.nan)

Advanced Profiler (Model Input):
  Input:  SondeHourly filtered by basic QA/QC
  NaN replacement:  ~5-15% (stricter thresholds)
  Output:  ~85-95% of routine records retained (high confidence data only)

================================================================================
KEY BUCKET SIZES & FREQUENCIES
================================================================================

Temporal Resolution:
  - Weather:        1 hour
  - SondeHourly:    1 hour
  - PFLStep:        2-3 per day (on-demand, depth-dependent)

Precision:
  - All numeric:    3 decimal places (float32/64 backend)

Validation Ranges (Strictness order):
  1. Routine scrape:  Minimal (NAN → 0, round decimals only)
  2. Weather QA/QC:   12 parameters validated against physical ranges
  3. Model input QA/QC:  Stricter profiler ranges, 10 parameters validated

NaN Handling:
  - Scrape stage:   "NAN" strings → 0 (for profiler); → np.nan (for weather)
  - Model stage:    Out-of-range → np.nan, then dropna() on critical cols
